# Defer full Arabic/RTL; ship i18n-ready, English-only

**Status:** PROPOSED pending PD-001 checklist classification

The working proposal is an English-only MVP with localization-ready strings, logical CSS properties, and correct round-tripping of Arabic user content. Final Arabic/RTL scope depends on the ITI checklist classification.

## Consequences

- Localization readiness reduces later rewrite cost.
- Do not claim full Arabic/RTL support without translated UI and RTL-specific tests.
