# Sprint Docs

Each sprint should have one planning file in this folder.

Use `../sprint-template.md` when starting a new sprint.

Minimum required sprint sections:

- Goal.
- Scope.
- Source requirements.
- Owners.
- Backend deliverables.
- API changes.
- Database changes.
- Docker/infra changes.
- Tests.
- Demo scenario.
- Risks.
- Definition of done.
