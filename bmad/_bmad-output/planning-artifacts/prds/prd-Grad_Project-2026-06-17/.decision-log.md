- 2026-07-21: Clarified the locked three-role direction: `OWNER` and
  `CONTRIBUTOR` remain account modes that select the primary product journey,
  but they are not exclusive project-ownership or contribution capability
  silos. Eligible accounts in either role may create and own projects and may
  contribute to projects they do not own without changing role. Persisted
  project ownership, applications, assignments, account status, and explicit
  Admin policy authorize each resource action. This supersedes interpretations
  that reserve ordinary project creation exclusively for `OWNER` accounts.
- 2026-07-21: Replaced automatic AI application gating with an advisory-only
  policy. AI may recommend and explain using permitted evidence but may not
  automatically accept, reject, hide, rank out, or eliminate an application.
  Insufficient evidence produces uncertainty or human review. This later
  decision supersedes the automatic blocking interpretation in FR-005, FR-018,
  and FR-051 through FR-059 pending editorial PRD synchronization.
- 2026-07-21: Approved GitHub identity and repository-control boundaries.
  GitHub OAuth establishes identity only. Private repository access and
  organization/shared repository control require an active GitHub App
  installation and explicit repository selection. A matching authenticated
  GitHub identity may prove control of a public personal repository without
  authorizing private access. Repository access remains read-only, revocable,
  least-privilege, and private evidence must not enter public outputs.
